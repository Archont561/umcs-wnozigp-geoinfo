## Goal

Define public behavior and supported workflows separately for LaTeX and Typst, including citations, before adding reusable template code.

## Grouped tasks

| Task | Work |
| --- | --- |
| TASK-4 | Approve the LaTeX API, engine, and editor contract in SPEC-LTX. |
| TASK-5 | Approve the Typst API, compiler, and distribution contract in SPEC-TYP. |
| TASK-6 | Compare bibliography/citation options and decide what evidence or local rules apply in SPEC-BIB. |

## Exit criteria

Each format contract identifies supported versions, dependencies, install/build commands, limitations, and acceptance evidence. Bibliography decisions are supported by source review, not by repo topics or defaults.
